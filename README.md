# Topologische Supraleitung und Majorana-Qubits — interaktive Begleitseite

Begleitseite zur Bachelorarbeit *Topologische Supraleitung und Majorana-Qubits.
Von der BCS-Theorie zum Tetron-Experiment* (Heinrich-Heine-Universität Düsseldorf,
Institut für Theoretische Physik).

**Seite:** https://kellermann11.github.io/majorana-viz/

Sechs Reiter — Kitaev-Kette, Rashba-Nanodraht, Energieskalen, Auslese, Gatter,
InAs–Pb-Tetron. Über jedem Panel steht der Satz aus der Arbeit, den es sichtbar macht;
der grüne Knopf „Vorführen" spielt die zugehörige Einstellung ab. Direktlinks der Form
`…/#nanodraht/A` öffnen ein Panel und starten seine Vorführung.

Reines HTML, CSS und JavaScript, ohne Build-Schritt und ohne externe Ressourcen;
`index.html` läuft auch lokal per Doppelklick.
